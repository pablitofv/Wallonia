# Valonia (Wallonia): a walk, film by film

**[Watch it: https://pablitofv.github.io/Wallonia/](https://pablitofv.github.io/Wallonia/)** · [About this project](https://pablitofv.github.io/Wallonia/about.html)

Thirteen days on foot across Wallonia, Belgium, from a room in Lille to a chapel in Maastricht (July 2025): every short film made along the way, played in order with its sound, beside a map that walks the same ground. East up, because east is where the walk went. A 3D view brings the camera down among the buildings on real terrain.

**A creative vibecoding project.** Made by Pablo Fernández Vallejo with Claude Opus 5.5 (Anthropic), by conversation in Claude Code: no framework, no build step, no tracker. Every decision about the line, the order of the films and the motion of the map was measured, not guessed.

Built with MapLibre GL, PMTiles, OpenStreetMap data via Protomaps, Mapterhorn terrain, the OpenStreetMap walking router and ffmpeg. Served as static files from GitHub Pages under a strict content security policy.

This repository holds only the published site, and only its current version: each update replaces it.

Map data © OpenStreetMap contributors, Protomaps; terrain © Mapterhorn.
